# Epistemic status legend

| Tag | Meaning |
|-----|---------|
| **Axiom** | First principle or iron law; formulation replaceable |
| **Cited standard theory** | External mathematics; framework interface only until Mathlib-backed |
| **Phenomenological** | YXT construction; formal proof pending |
| **Axiomatic construction framework** | `def`/`inductive`/`axiom` scaffold from the axioms |
| **Proven** | Zero-sorry Lean theorem in this repo or docked repo |

Every `.lean` file must state its status in the module docstring.
